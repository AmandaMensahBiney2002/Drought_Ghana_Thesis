# Drought Monitoring and Prediction System for Ghana

## Project Overview

This project develops an interactive monitoring and prediction system for drought in Ghana using:
- **CHIRPS** satellite rainfall data
- **Standardized Precipitation Index (SPI)** at 1, 3, 6, and 12-month timescales
- **Machine learning models**: LSTM, Random Forest, XGBoost, and SVR
- **Interactive web dashboard** built with Streamlit
